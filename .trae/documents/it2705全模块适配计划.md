# IT2705 全模块适配计划（consumption_test / pmu_test / charger_test / module_test / orchestrator）

## Context

IT2705（8 通道源载系统）目前仅 power_analyzer 页（analyser/datalog/suite）完成适配；连接层（`N6705CConnectionMixin`、`InstrumentManager` registry `_create_n6705c`）已统一走 `factory.create_power_analyzer(analyzer_type="auto")` 自动识别 N6705C/IT2705。但其它以 N6705C 命名的模块存在三类不兼容：

1. **驱动缺口**：业务层调用 N6705C 专属方法（IT2705 驱动缺失）：`set_channel_range(_off)` / `set_sense_mode` / `set_voltagemode` / `prepare_force_high` / `prepare_force_auto` / `restore_channels_to_vmeter` / `read_mmem_data`。
2. **通道数硬编码**：UI 通道下拉/选择器写死 1–4（IT2705 为 1–8）。
3. **型号耦合**：`view_device.py` 绕过 factory 直接 `N6705C(visa)` 且校验 `"N6705C" in idn`；各页硬编码 "N6705C" 文案。

用户已决策：iterm_test 用 ELOG 重构支持 IT2705；通道选择器全部动态化；文案改为型号感知。缺失接口一律以 `tests/_it2700_prog_guide.txt`（IT2700 编程手册提取文本）为准，不臆测；真机实测地址 `TCPIP0::10.31.71.168::30000::SOCKET`。

## 改动清单

### 1. IT2705 驱动补齐 — [instruments/power/itech/it2705.py](../../instruments/power/itech/it2705.py)

手册依据 + 与 N6705C 同语义：

| 方法 | 实现 | 依据 |
|---|---|---|
| `set_channel_range(ch)` / `set_channel_range_off(ch)` | **no-op**（debug 日志说明） | 手册 SENSe 子系统仅有 `SENS:VOLT:RANG:AUTO`（电压自动量程），**无电流量程/自动量程命令**，IT2700 电流测量无此概念；业务调用点众多（dcdc_worker×3、module_test×3、orchestrator×2），驱动 no-op 使业务零改动 |
| `set_sense_mode(ch, mode="INT")` | `SENS ON/OFF,(@ch)`（即 `SENSe[:REMote][:STATe]`） | 手册 §15 SENSe 子系统；mode_map 与 N6705C 对齐：INT/INTERNAL/LOCAL→OFF，EXT/EXTERNAL/4WIRE/"4 WIRE"/4-WIRE→ON，非法值 ValueError |
| `set_voltagemode(ch)` | `set_mode(ch, "VMETer")` | 手册 EMUL 列表含 `VMETer`；IT2705.set_mode 对 PS 模式自动补 FUNC VOLT 的既有逻辑不受影响（VMETer 不在 PS_EMULATION_MODES） |
| `prepare_force_high(channels, voltage_offset, current_limit, monitor_channels=None)` | 复制 N6705C 组合逻辑：VMETer→on→0.5s→测压→PS2Q+set_voltage(measured+offset)+set_current_limit→on→0.5s，返回 measured_voltages | 纯组合（set_mode/measure_voltage/set_voltage/set_current_limit/channel_on IT2705 均已具备） |
| `prepare_force_auto(channels, current_limit, monitor_channels=None)` | 同上，电压经 `_align_voltage`（0.05 网格 + 特殊值 `[0.625,0.67,0.725,0.78]`，final_limit 规则 0.07/0.15） | 复制 N6705C `_AUTO_SET_SPECIAL_VOLTAGES` + `_align_voltage` 静态方法 |
| `restore_channels_to_vmeter(channels)` | VMETer + channel_on，逐通道 try/except 吞异常 | 纯组合 |

**明确不实现**（有依据，业务侧守卫）：
- `read_mmem_data` — IT2700 内部 DLOG 数据无 SCPI 读回口（instruments/AGENTS.md 已有真机实测结论）；波形唯一路径 = ELOG。
- `wait_arb_idle` — 手册无 ARB 运行态查询命令；`core/module_test/_common.py` 已 hasattr 守卫降级固定等待。
- `force_high_and_measure` — 全仓无调用方（死代码）。
- `test_arb_staircase / test_line_transient_arb / test_load_transient_arb` — 仅 `tests/` 调试脚本与驱动 `__main__` 自用。

### 4. iterm_test ELOG 重构 — [ui/pages/charger_test/iterm_test.py](../../ui/pages/charger_test/iterm_test.py)

- 以 `callable(getattr(self._n6705c, "read_mmem_data", None))` 分支：
  - **N6705C**：现有 DLOG 下载 + `parse_dlog_binary` 路径不变。
  - **IT2705**：ARB 配置相同（IT2705 已有 `set_arb_staircase/arb_on/arb_run/set_arb_continuous`）；采集改走 ELOG——`configure_elog(curr_ch, volt_ch, sample_period_s)` + `start_elog()`，ARB 运行期间每 0.2s `fetch_elog_records(ch)` 流式回读（模式参照 [ui/pages/power_analyzer/datalog/workers.py](../../ui/pages/power_analyzer/datalog/workers.py) `_fetch_elog_units`：时间轴=记录序号×实际 PER，V/A→mV/mA），收尾先排空再 `stop_elog()`（ABOR 即清缓冲）。
  - 产物对齐 `parse_dlog_binary` 输出结构 `{label: {"time":…,"values":…}}`，下游分析代码不变；`range(1,5)` 的 DLOG FUNC OFF 循环按 `VALID_CHANNELS` 展开。
- Mock 冒烟：MockIT2705 ELOG 已仿真（正弦数据），ELOG 路径可跑通。
