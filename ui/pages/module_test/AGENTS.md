## 本模块职责与边界

- **职责**：Module Test（LDO / DCDC）隐藏 Tab 容器。

## 局部约定

> 共享 `_common.py` 助手的测试项 LDO/DCDC 两侧天然同步；以下各条不再重复标注同步状态。

- **LDO / DCDC 同名测试项双向同步（硬规则）**：更改任一侧测试项时，必须评估另一侧同名项（共用 `_common.py` 助手的尤其）的流程/参数/判定是否需同步；不同步须说明理由。两侧改动须在同次变更内完成（或明确豁免），并同步更新本文件。
- **单项测试分组**：LDO `ldo_dropout`/`ldo_current_limit` 在 `ldo_test_ui.STANDALONE_ITEMS`（「单项测试」组；「全选」只作用「自动测试序列」组，runner 按 `selected_items` 执行不变）；DCDC 侧豁免（用户指令限定 LDO，且无 dropout 项）。
- `measured` 用 `list[dict]`（非 `{"rows":[...]}`）才能被 `_measured_to_rows` 渲染成正表（quiescent 现为 dict，单列 `dIvin/dIvout/Iq`）。
- quiescent：单点差分测（`iq_diff_measure`），CSV `["dIvin (uA)","dIvout (uA)","Iq (uA)"]`；ENABLE 用 DR/EN BIT 单 bit 位写（`set_dut_enable`）。
- **示波器 Vout 通道统一走 DUT Config**：`scope_vout_ch_combo`（存 `scope_vout_channel` 入 cfg），各 scope 项 `cfg.get("scope_vout_channel", 1)` 读取；禁止再在测试项 ParamSpec 加该参数（已收敛）。
- **电压测试方式（volt_method）**：DUT Config 下拉存 `volt_method`：`n6705c`（默认，Vout 通道电压表）/ `scope`（示波器通道均值，DSOX=`MEAS:VAVerage`/MSO64B=`MEAN`）；仅 N6705C 方式显示「Vout 通道」行（`_row_vout` 联动显隐）。core 唯一出口 = [_common.py](../../../core/module_test/_common.py) 的 `measure_vout()`（多次采样去极值均值）与 `setup_vout_meter()`（scope 方式入位：500mV/div 读 V0 → offset=V0 归中 → 50mV/div 精量程，并开显示/强制 DC 耦合/DSOX 触发 AUTO/恢复 RUN）。**铁律**：①SCPI 写序必须先 scale 后 offset（改 scale 时示波器按比例重算 offset，先写 offset 会被缩成 1/10）；②入位缓存 `_SCOPE_VOUT_CACHE`（键=scope 通道+标称 Vout）——runner 基准阶段（`_record_vout_baseline`，序列开头）`force=True` 全量入位写缓存，后续项默认快路径重放 scale/offset（不重读 V0 不打日志）；读数越窗 [V0±200mV] 时 `force=True` 重走完整入位复测一次。禁止测试项直接 `measure_avg(ctx,"measure_voltage",vout_ch,...)` 测 Vout（Vin/电流测量不受影响）；scope 方式 `_missing_instruments` 强制示波器已连接；quiescent 的 `vout_src_ch` 是外供源不参与切换。
- **Vertical Offset 一律归中（全部示波器入位点）**：①Vout 表 `offset = V0`，越窗判定对称 [V0±200mV]；②Transient `_measure_with_autoscale` 先读回 `get_channel_scale` 比对，仅 scale 实际变更才写 scale 并以标称 Vout 临时入位（scale 不变沿用当前 offset，不再拉偏再拉回）；STOP 定格测完 Vmax/Vmin/Vmean/Vpp 后把 offset 重写为实测均值归中（STOP 态改 offset 仅重定位显示、不影响冻结帧测值，定格帧直接供截图）；③两驱动 `set_AutoRipple_test` 精档 `offset = mean`。写序同①（先 scale 后 offset）。FFT `offset_db` 是 dB 刻度参考电平，不在本规则内。
- **Vout 扫描前置校验/尾部饱和 → 用户确认弹窗**：`run_vout_scan` 前 N 点校验失败（`_precheck_first_points`，中文原因）或连续 N 点尾部饱和（`_TAIL_STOP_*`）时经 `ctx.confirm_fn` 弹窗。链路：item → runner `confirm_request(str,str)` → 基类 `_on_confirm_request` 中文 QMessageBox（继续/中止，默认+Esc=中止，`apply_qss(box,"dialog")`）→ `respond_confirm`；runner 用 `threading.Event` 阻塞等待（`_wait_user_confirm`）且期间可响应 Stop。前置校验仅问一次，选继续则剔除已测异常前缀并复述已测点（CSV 保留原始数据，性能指标自动排除）；饱和选继续置 `saturation_continue` 本次不再问；选中止截断平台后 break。寄存器默认值恢复在 `finally` 兜底（覆盖停止/异常路径）。Mock 跳过两项检测。
- **Vout 扫描与 PMU 双向同步（硬规则）**：`run_vout_scan`（前置校验/饱和常量、弹窗文案、异常前缀剔除语义、finally 恢复策略）与 [pmu_output_voltage.py](../pmu_test/pmu_output_voltage.py) 的 `OutputVoltageTestThread` 逻辑一致；任一侧改动须在同次变更内同步另一侧 + 两侧 AGENTS.md（另一侧为 ui/pages/pmu_test/AGENTS.md）。**豁免**：Vin 偏置与 Vout 测量来源不在同步范围（PMU 页测量路径自理）。
- **Vout Scan Vin 偏置**：两侧注册表 `vin_bias()`（`vin_v`，输入偏置默认 3.8V）；`run_vout_scan` 开局 `setup_source_channel(ctx, vin_ch, vin_v, current_limit=0.5)` 把 Vin 通道（`vin_channel`，DUT Config）置 PS2Q 上电；固定偏置非扫 Vin，收尾不 `restore_vin`（同 quiescent/ripple 等固定 Vin 项）。
- **Vout Scan Vout 改读 Iload 通道电压**：扫描全程（默认值/min_code 稳定等待/逐码测量）不走 `measure_vout`/`setup_vout_meter`，由项内闭包 `_scan_vout()` 直接 `safe_measure(n6705c,"measure_voltage",iload_ch)`（CCLoad 通道并接 DUT 输出，`MEAS:VOLT?` 单次查询，免示波器入位与越窗复测）；日志 `[TEST] Vout readback via Iload channel CHx`。measured/CSV 字段与判定不变；逐项 Vout 偏差门禁（`_runner_base` 走 `measure_vout`）与其余项 `volt_method` 机制不变。
- **判定标准**：各测试项「设置」弹窗（ItemParamsDialog）内 QTabWidget——「参数」页 +「判断标准」页（仅命中 `JUDGE_METRICS` 时出现，[dialogs/judge_dialog.py](./dialogs/judge_dialog.py) `JudgeCriteriaTab` 逐行 启用/条件/阈值）；OK 时 `_apply_item_judge_rules` 原地写回 `judge_criteria[item_key]`（ModuleConfigStore 共享引用，随模块配置持久化）。引擎在 [core/module_test/judge.py](../../../core/module_test/judge.py)（纯函数，指标注册表以 items 实际 `measured` 键为准，支持 dict 标量/list[dict]/`{"rows":无键行}` 按列提取；全部满足才 PASS，无数据保持 N/A）；runner `_apply_judge` 仅判 `passed=None`（异常 FAIL 不覆盖），verdict 进 summary/报告/计数。**与报告异常标红（table.rules 前端引擎）是两套独立机制**。
- **Module Config**：LeftRail「Module Config」Card（`ModuleConfigPanel`）——启用勾选 + YAML/指令编辑（`QPlainTextEdit#moduleConfigYaml`，样式在 controls.qss）+ 手动执行；指令格式复用 Consumption 电源轨（`WRITE/WRITE_BITS/READ`，可带 `DUT:` 前缀），地址/位宽直接取 DUT 配置 `device_addr`/`width_flag`（不经 bes_chip_check）。解析/执行在 [core/module_test/module_config.py](../../../core/module_test/module_config.py)（`parse_config_commands`/`run_module_config` 纯函数 + `ModuleConfigWorker` QThread）；持久化键 `module_config_enabled`/`module_config_yaml`。勾选启用后 `_on_start_test` 先后台下发再 `_proceed_start_test`（失败仅记日志不阻断）；手动执行经 `execRequested` 共用 `_run_module_config(after)` 链路。
- 添加新测试项时，对于非供电的电源仪器，需要先重置仪器状态，再去进行测试。
- **Test Item 运行状态**：runner `item_started(str)` 信号（每项跑前发射）→ 基类 `_enter_run_state` 锁定勾选（运行期禁改）+ 记录列显示 等待中/未选 → `_mark_item_running`→进行中 / `_mark_item_done`→PASS/FAIL/完成(N/A) → `_exit_run_state` 复原。`_refresh_scope_item_state` 有 `is_test_running` 守卫（运行期顶层连接同步不得覆盖状态列）。
- **逐项 setForeground 被全局 QSS 盖掉（坑）**：`get_table_qss()` 在 `QTableWidget` 选择器设的 `color` 优先级高于 item 的 ForegroundRole，逐项染色全灰。修复 = 表实例级 `setStyleSheet("QTableWidget { color: palette(text); }")` 关掉 QSS 调色板（只影响本实例，不改共享 QSS）。**任何靠 setForeground 逐项染色的 QTableWidget 都需此招**。
- **Load/Line Transient 共用流程**（`_common.run_load_transient`/`run_line_transient`）：开局 `_reset_arb_state` 清残留（arb_stop + 全通道 [1,2,3,4] wait_arb_idle + 本项通道 exit_arb_voltage/current + **其它通道 `set_arb_shape(ch,"NONE")` 清遗留形状配置**，防 BUS 触发误带起旧通道脉冲；本项通道不置 NONE）→ Load：CCLoad+Slew MAX+电流 ARB Pulse（I0/I1 取负）/ Line：Vin 通道 PS2Q+电压 ARB Pulse（Vin0/Vin1 正压）（均 t0=T/2、t1=0、t2=T/2）→ `set_arb_continuous(ch,True)`（`ARB:COUN INF`，须在形状配置后、arb_on 前写）→ `restore_arb_trigger_source()`（TRIG:ARB:SOUR IMM，须在 INIT 前写；armed 后写报 +308 不触发）→ `arb_on` → 示波器 `close_all_channels()`+`set_waveform_intensity(100)`（MSO64B 部分固件不支持则 best-effort 忽略）→ 量程/时基 → settle → stop 截图 + Vmax/Vmin/Vmean/Vpp 算过冲/欠冲 → 每组收尾 `arb_stop`+`set_arb_continuous(False)`+`exit_arb_current`（Line 为 `exit_arb_voltage`；**收尾不关 VIN**，须 `set_voltage(vin_v)` 恢复正常输出，否则后续项 DUT 掉电全挂）。参数 ptype="groups"（`transient_groups()`/`line_transient_groups()` 各默认 3 组，弹窗 `_GroupsEditor` 可增删，无 base_key 全量返回）；CSV 第 0 列组号，截图键 `{"Group": str(组号)}`（报告按 `Group N` 渲染并按 CSV 首列锚定数据行）。时基=period/2；`dcdc_line_transient` 注册表默认不勾选。
- **示波器自动扩量程 + 两阶段时基**：Vmax/Vmin/Vmean/Vpp 一律走 `_measure_with_autoscale`——削波（无效值 9.9e37；DSOX 抛 `MeasurementError`、MSO64B `ValueError`）按量程×2 重试（Load max_tries=6 上限 320mV/div、Line 5，均 10mV/div 起步）；**重试前必须 `run()` 恢复采集再 settle**（停采态改量程/时基只重绘旧帧拿不到新波形），被扩量程时 UI 日志提示。每组两阶段：预览时基 `period/10×1.1`（等 `max(1s,16×preview)`，首组 Load 额外 +3s）下做 autoscale 量程搜索（测量值仅供削波判定）→ `run()` → 切最终时基 period/2 正式测量（max_tries=1，改量程后等 16×最终时基并 stop 定格）→ 返回即稳定 stop 帧直接截图，**勿再 run/stop**。STOP 态测量不触发重捕（`_meas_refresh_s` STOP 返回 0；四个查询各 0.2s，测后仅 0.3s 标注渲染）。**Vertical Scale 确认/继承**：`_transient_confirm_vdiv`+`_TRANSIENT_VDIV_CACHE`（键=kind(load/line)+scope 通道+标称 Vout，Load/Line 分桶互不继承）——每 kind 首个 transient 项首组完整确认入缓存（记日志「确认完成」），同 kind 后续组与另一模块同 kind 项直接继承（量程由阶段二重新下发）；阶段二失败则 `_transient_invalidate_vdiv` 清缓存 → `run()` → 重确认+复测各一次，仍失败单组降级记 0。
- **报告记录仪器 \*IDN?**：`ModuleTestResult.instruments`（list[dict]，runner 开局 `_collect_instruments`）→ `build_report_data` 填 meta.instruments；取值优先级 `identify_instrument()`（示波器）→ `identify()` → `.instr.query("*IDN?")`（N6705C 无 identify 靠此）；失败静默跳过不阻断。Mock 得空串被跳过，故 Mock 报告无仪器行。
- **全自动流程通道自控**：VIN 通道不干预（DUT 上电态由前置工序保证）；其余通道每项开局强制入位——`setup_meter_channel`=VMETer+range+**channel_on**（缺 channel_on 则 measure_voltage 恒 0）；`setup_load_channel` 支持 `initial_current_a`，**先写电流再 channel_on**；`teardown_load` 只 `channel_off` 不归零（硬红线 12）；dcdc_efficiency baseline 在负载通道开启前测；dcdc_quiescent 不配 load 通道（外供 Vout 源已够，0mA 拉载触红线）；`run_vout_scan` 走 `setup_meter_channel` 不裸 `set_mode`。
- **Quiescent 收尾关断外供而非设 0V**：PS2Q 设 0V 仍 channel_on，会把 VOUT 节点拉 0V 致异常——须 `channel_off(vout_src_ch)`；关断前还须还原 ENABLE 寄存器（`set_dut_enable` 返回写入前位值，`iq_diff_measure` 第 4 返回值带出，用 `restore_dut_enable(ctx, en_regs, d[3])` 还原，否则后续项在 DUT 关断态下跑）。
- **示波器通道显示联动**：transient 之后的项须显式 `set_channel_display(scope_ch, True)`（transient 调过 `close_all_channels()`，不开则全程平线）；`_measure_with_autoscale` 重试耗尽抛异常时外层先 `ctx.scope.run()` 恢复采集再降级（防停采态污染下一组/项）。
- **DCDC Switching Frequency**：扫负载+AC 耦合测输出纹波频率——参数 `vin_bias()`+`load_sweep()`+`average_cnt()`+`settle_time()`（示波器通道走 DUT Config）；每负载点 `set_AutoRipple_test` 自动优化档位后按平均次数测 `get_channel_frequency` 取均值；**收尾必须恢复 `set_channel_coupling(ch,"DC")`**（否则后续 DC 项测不到直流分量）；`measured` 用 list[dict]（`Iload (mA)`/`Fsw (kHz)`），report 有 Fsw-Iload 曲线分支。
- **首项前 Iload 预拉载**：`_runner_base.run()` 在模块配置后、第一项前 `_preload_iload()`——Iload 通道（`iload_channel` 默认 3）`setup_load_channel(ch, initial_current_a=0.001)` 先写 -1mA 再 channel_on（满足 CCLoad 禁 0mA 开机红线）→ settle 1s（Mock 跳过）→ `teardown_load` 仅 channel_off。顺序在 V0 基准记录**之前**。日志 `[PRE]`。
- **Max Iload → Vin 通道限流**：DUT 配置「Max Iload (mA)」（`max_iload_spin`，QSpinBox 0~10000 默认 400，旧配置缺键回落同值）存 `max_iload_ma`（ModuleConfigStore collect/restore）；唯一计算出口 `_common.vin_current_limit_a(cfg)`（`max_iload_ma/1000+0.1` A）。生效两处：runner `_setup_vin_current_limit()`（`_preload_iload` 之前，`[PRE]` 日志，失败降级 WARN 不阻断）+ 各项 `setup_source_channel(..., current_limit=vin_current_limit_a(cfg))`（勿再硬编码 0.5，会覆盖测试前设置）。**豁免**：`ldo_current_limit`(1.0A)/`dcdc_current_limit`(1.5A) 需高于 DUT 限流点保留原值；`iq_diff_measure` 的 `vout_src_ch` 是外供源不在范围。校验脚本 [tests/check_vin_current_limit.py](../../../tests/check_vin_current_limit.py)。
- **逐项 Vout 偏差门禁**：[_runner_base.py](../../../core/module_test/_runner_base.py) `run()` 第一项前 `setup_vout_meter`+`measure_vout`（`_VOUT_GUARD_SAMPLES=3` 去极值均值）记基准 V0（`[VOUT]` 日志）；每项结束（`item_finished` 后）复测，偏差超 ±20mV（`_VOUT_GUARD_LIMIT_V`）记 `[ERROR]` 并 break（已跑项保留、报告照常，原因记 `summary["aborted"]`）；测量出口唯一 `_common.measure_vout`（随 volt_method），门禁前 `setup_vout_meter` 幂等入位；读取失败（nan）仅 WARN 降级跳过不误停。Mock 噪声 σ=2mV 不触发。
- **Load Regulation Vout 跌落保护**：两侧 `load_line_reg` 逐点测量后 Vout < 标称（`vout_nominal_mv`）×70%（`_LOAD_REG_VOUT_DROP_RATIO=0.30`）记 `[ERROR]` break 终止本项扫描（触发点仍写 CSV，`teardown_load` 正常收尾，runner 继续后续项），结果 `passed=False`+notes 说明。仅真机路径判定（Mock 轻微跌落不触发）。
- **Load Regulation 复用 Ripple 参数（follow_switch）**：`*_load_reg` 弹窗顶部开关「直接使用 Load Capability&Ripple 测试值」（仅 ripple 已勾选才可开，否则置灰+强制关闭清历史态）；状态存 override 键 `use_ripple_sweep`（仅开启时导出）。runner 侧（override 合并后）：为真且 ripple 在 selected 内时按 ripple ParamSpec 逐键整组覆盖 item_cfg（取值链 ripple override → 基类 cfg → spec 默认，日志 `[CFG]`）；ripple 未勾选 `[WARN]` 回退本项参数。`load_knee` 为 load_reg 独有不在覆盖。**连带**：`load_line_reg` 拉载走 `apply_load_current`（0mA 点 channel_off 而非设 0mA，硬红线 12）。
- **Line Regulation Vout 改读 Iload 通道电压**：`line_reg` 逐点测量不走 `measure_vout`/`setup_vout_meter`（项内已删 Vout 表入位；`average_cnt` 注册表保留但本项不生效），由项内闭包 `_scan_vout()` 直接 `safe_measure(n6705c,"measure_voltage",iload_ch)`（同 Vout Scan：CCLoad 通道并接 DUT 输出，`MEAS:VOLT?` 单次查询）；项开始 `setup_load_channel(ctx, iload_ch, initial_current_a=0.001)` 全程挂 1mA 轻载（先写电流再开通道），收尾 `teardown_load`（不归零）+ `restore_vin`；日志 `[TEST] Vout readback via Iload channel CHx`。runner 逐项 Vout 偏差门禁与其余项 `volt_method` 机制不变。

## 局部坑点

- 样式：`_setup_style = get_page_base_qss() + get_table_qss() + START_BTN_STYLE + page_extra`，色值只取 `ui.theme` token；启停按钮 objectName 固定 `primaryStartBtn`/`stopBtn`。严禁把 `START_BTN_STYLE`（整段带选择器的 QSS）嵌进 `#xxx{...}` 声明块——无效 QSS，样式静默失效。
- 结果落 `Results/module_test/{module_type}/{芯片}_{模块}_{时间戳}/`（`_runner_base._safe_dir_part` 清洗 Windows 非法字符、空段省略、全空回落纯时间戳）；新增测试项落 `core/module_test/{ldo,dcdc}/items/`。
- **XLSX 导出**：[core/module_test/xlsx_export.py](../../../core/module_test/xlsx_export.py)（纯函数无 Qt）。截图锚定：`measured["screenshots"]` 的 `Iload (mA)` 键按 CSV 首列数值匹配数据行（行高 `px×0.75+4`），未匹配/单波形（`waveform_png`）堆叠数据区下方每行一张。依赖 openpyxl+Pillow（缺则 RuntimeError 不静默丢图；spec hiddenimports 已加）。入口仅两处：报告页「下载 XLSX」与报告目录 `XLSX/`。
- **报告内单项 XLSX**：`save_html_report` 自动在报告目录 `XLSX/` 为每个有内容（数据表或截图）项生成 `{item_key}.xlsx`（`export_items_xlsx_dir`，best-effort 不阻断，空项跳过）；`build_report_data(xlsx_map)` 注入 `item.xlsx`，前端渲染「下载 XLSX」按钮与「下载 CSV」并列；单项与整报告导出共用 `_write_item_sheet` 锚定逻辑。
- **复制表格（含截图）**：`copyTableRich`（`data-tact="copyrich"`，仅含 `kind:image` 列的表渲染按钮）写 `text/html`（`<table>`+`<td><img src=dataURI>`）+ `text/plain`（TSV）——浏览器原生复制会被 Excel/飞书丢弃 button 内图片。**限制**：Excel 粘贴图片必为浮动层（已加行高+图片固定 240×135+列宽锚定防重叠）；飞书云文档粘贴剥离 `<img>` 只留文本（平台限制剪贴板侧无法绕过，toast 已引导走「下载 XLSX」）。
- **item 整卡复制截图**：卡片头「复制截图」（`data-act="shot"`，内联 SVG 图标 `ICON_SHOT`，禁 Emoji；i18n 键 `copy_shot/shot_copied/shot_fail`）→ `copyItemShot(sec)`：克隆 `.item` 注入全量 CSS → `<foreignObject>` 包成 SVG（`data-theme` 挂 svg 根使 CSS 变量按当前主题解析）→ 2x canvas 光栅化 → 粘贴板 PNG，失败降级下载 `{item_key}.png`。约束：截图均 dataURI、CSS 无 `url()` 外链、图表 SVG 颜色为显式属性（非 CSS var），故静态渲染无外链依赖；折叠/懒展开按当前已渲染 DOM 截。事件委托在 `#items` click（`data-act='shot'`，注意与 `.shot` 缩略图类名区分）。
- **逐点截图进报告**：测试项把每张截图追加 `measured["screenshots"]`（`[{"Iload (mA)":..,"png":路径}]`）→ report.py 转 `items[].attachments`（base64 dataURI）渲染缩略图网格+灯箱；有 screenshots 时 `waveform_png` 单图抑制避免重复。报告数据出口唯一：`build_report_data(result)` → `build_module_html_report`；测试项异常标注走 `table.rules` 前端引擎（gt/lt/abs_gt/eq/outlier/constant）。**版式要点**：Ripple 截图并入数据表末列（`kind:image` 存 attachments 下标按 Iload 匹配，不重复内嵌 base64）；Load/Line Reg 图为 Catmull-Rom 平滑折线（series `smooth`，无散点/拟合）；Transient 仅数据表+截图网格（分组柱状图已删）；Vout Scan 首列 DAC_code 显示 Vbit（`fmt:vbit`，列标题下拉 `select[data-vbsel]` 切进制带 localStorage 记忆，CSV 仍十进制）；异常行首图标固定槽位（`rowflag--ph` 占位）；Vout Scan 异常 diff 柱 5×MAD 标红（`bar_anomaly`，与表格规则一致）。
- **示波器连接联动**：mixin `_on_mso64b_top_changed` 只更新 `scope_connected` 不刷新测试项表；子页基类必须覆盖它追加 `_refresh_scope_item_state()`（running 时除外），否则连接示波器后 (scope) 项残留"未接示波器"提示。
- **逐节点 DEBUG**：`debug_config.MODULE_TEST_DEBUG=True`（改值须重启）→ ①逐节点截图：`run_load_capability_ripple` 各流程节点 + DSOX `set_AutoRipple_test` 内部 8 步（`debug_shot_cb` 钩子）+ `run_load_transient`（组标签同报告 `g{组号}_{频率}Hz`，经 `_measure_with_autoscale` 可选 `debug_shot` 钩子），落报告目录 `debug/`（`run_line_transient` 未接入，需要时照 Load 移植）；②事件日志 `_common._debug_event` 写 `debug/events.log`（`[YYYY-MM-DD HH:MM:SS.mmm][+相对s] 事件`，每项锚定 `ctx._debug_t0`，跨项追加共用同文件）。截图节点与事件逐行对照即可定位问题步骤。默认关闭零开销。
- **截图前暂停采集是全局铁律**：任何 `capture_screen_png` 前必须让示波器处于 stop 定格态（run 态刷新中会截到过渡帧/空帧），截图后 `run()` 恢复采集。标准范式 = `is_acquiring()` 感知原状态 → 未停则 `stop()`+等 ≥0.2s 一整屏 → 截图 → finally 按原状态恢复（原本已停不恢复）。**截图前有 DISPlay 测量查询（pk2pk/rms/mean/max/min）时，测量与截图之间须等刷新完成**（添加测量项触发全屏重捕会冲掉定格帧）：`_measure_with_autoscale` 内部已统一处理（维持"返回即 stop 态可截图"契约）；ripple 在 `measure_vout` 后、正式截图前 `settle(1.0)`。**例外**：①Transient 在 `_measure_with_autoscale` 返回帧上直接截图，勿再 stop/run（外层只自己收尾 run）；②AI 动作（core/ai handlers）手动截图是"截当前屏"语义不改。合规参考：`_capture_scope_png`、`_debug_scope_shot`、`_measure_with_autoscale`、LDO output_noise FFT（截图前 3s 积累）、PMU `_restop_after_measure`。
- **测试项勾选与启动校验**：所有项始终可勾选，未接示波器不再禁用/反勾选 (scope) 项，仅记录列显示"未接示波器"提醒；启动时 `_missing_instruments(cfg)` 统一校验全程所需仪器（N6705C+勾选项示波器依赖，DEBUG_MOCK 放行），缺仪器 `_on_start_test` 记 `[ERROR]`+弹 `QMessageBox` 阻断，`ai_start_test` 同步返回失败原因。
- **ItemParamsDialog override 语义**：无 `base_key` 的项级参数（reg_addr/msb/lsb/min/max_code 等）`get_override()` 必须全量返回（显示即生效；diff 语义会把被 msb/lsb 联动改写的 max_code 误判"未改"丢弃，致扫错寄存器）；有 base_key 的基类参数才用 diff（未改回退基类 cfg）。
- 单个测试项注意鲁棒性：通道设置顺序、是否需额外等待、测试前主动开通道、测试后是否关通道等；Vbat 通道不需要关闭（DUT 电源，关闭致 DUT 异常）。
- CCLoad 0mA 场景（硬红线 12 补充）：0mA 测试点直接关闭通道输出而非设 0mA；也禁止从 0mA 状态开通道——先设非 0 负载电流再 channel_on。
