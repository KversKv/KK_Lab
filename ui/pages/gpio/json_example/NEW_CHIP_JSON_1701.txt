新芯片 GPIO JSON 配置 - 填写示例（BES1701 已完成版）
======================================================================

本文件 = NEW_CHIP_JSON_TEMPLATE.txt 按 BES1701 实际数据填写后的样子，
对应生成物 = chips/gpio_configs/bes1701.json（AI 按本文件生成并自检通过）。
供填写其它芯片时对照参考。


----------------------------------------------------------------------
0. 前置硬约束
----------------------------------------------------------------------
BES1701 全部满足：bank 偏移 Out Set=+0x00 / Dir Set=+0x04 / Out Clr=+0x0C /
Dir Clr=+0x10 / Input Read=+0x50；每 bank 4 group x 8 pin；32bit 位宽；
I2C 设备地址自动取 chip_info["main_die_i2c_addr"]。


----------------------------------------------------------------------
1. 必填信息
----------------------------------------------------------------------

1.1 芯片名
    芯片名 = bes1701

1.2 GPIO banks（共 18 group → 5 bank；末 bank 高位 2 个 group 不存在）
    bank1 = AON_GPIO0  0x40081000
    bank2 = AON_GPIO1  0x40089000
    bank3 = AON_GPIO2  0x4008A000
    bank4 = AON_GPIO3  0x4008D000
    bank5 = AON_GPIO4  0x4008F000  groups=2
    （GPIO180~197 物理不存在，不显示/不参与批处理与统计）


----------------------------------------------------------------------
2. 输入上下拉
----------------------------------------------------------------------

2.1 pull_up_bases（与 banks 平行，每 bank 一个 32bit 寄存器、1bit/GPIO）
    pull_up_bases   = 0x40086084, 0x40086088, 0x4008608C, 0x40086090, 0x40086094

2.2 pull_down_bases
    pull_down_bases = 0x40086098, 0x4008609C, 0x400860A0, 0x400860A4, 0x400860A8

2.3 上下拉阻抗（欧姆，仅 UI 显示）
    pull_ohm.up   = 36437.24696
    pull_ohm.down = 35516.96922


----------------------------------------------------------------------
3. 输出驱动强度 drv
----------------------------------------------------------------------

3.1 寻址方式：A. per-group 显式地址表（地址区不连续，B 线性区已删）
    drv.group_bases（按 Group0~17 顺序，共 18 个）=
        0x40086060, 0x40086064, 0x40086068, 0x4008606C,
        0x40086070, 0x40086074, 0x40086078, 0x4008607C,
        0x40086080,
        0x400860EC, 0x400860F0, 0x400860F4, 0x400860F8,
        0x400860FC, 0x40086100, 0x40086104, 0x40086108,
        0x4008610C
    （0x40086084~0x400860E8 为 PU/PD 及其它寄存器区，Group9 起跳至 0x400860EC）

3.2 公共字段
    bits_per_gpio = 4        （每寄存器 8 脚，pin N 位域 [4N+3:4N]）
    levels        = 16       （档位 0~15，阻值越小驱动越强）

3.3 各档位输出阻抗表（欧姆，索引 = 档位值）

----------------------------------------------------------------------
4. func_sel 引脚复用
----------------------------------------------------------------------

4.1 基本字段
    base          = 0x40086004    （每 group 一个 32bit 寄存器，地址 = base + group*4，
                                   Group0~17 → 0x40086004~0x40086048）
    bits_per_gpio = 4
    gpio_value    = 0xF           （sel 位域写 0xF 选为 GPIO 功能）
    groups        = 18

4.2 functions iomux 复用功能表
    数据源：Temp/bes1701_iomux.xlsx（由 tests/gen_bes1701_iomux.py 注入 JSON）。
    格式示例（"GPIO_P{group}_{pin}": [Func_0..Func_N]，list index = sel 位域值，
    未用值补 null）：

    GPIO_P0_0 = [SEN_SPI3_CLK, LP_I2C3_SCL, LP_UART0_CTS, AP_SPI3_CLK,
                 null, smp_bt_pin1, null, null, null, null, ana_test0]
    GPIO_P0_1 = [SEN_SPI3_D0_I, LP_I2C3_SDA, LP_UART0_RTS, AP_SPI3_D0_I,
                 null, smp_bt_pin0, null, null, null, null, ana_test1]
    ...（GPIO_P0_2 ~ GPIO_P17_7 共 144 脚同格式，完整内容见 xlsx /
         chips/gpio_configs/bes1701.json 的 func_sel.functions 段）


----------------------------------------------------------------------
5. 备注
----------------------------------------------------------------------
- drv 地址区不连续（PU/PD 区穿插其中），故必须用 group_bases 显式地址表而非线性 base。
- 末 bank AON_GPIO4 仅 2 个有效 group（Group16~17）。

2. Detect DUT 后自动加载，Matrix 显示 5 bank / 18 group / 144 脚；
