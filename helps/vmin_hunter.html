VminHunter（最低工作电压探底）

页面介绍

VminHunter 用于探测芯片能稳定工作的最低电压边界（Vmin）。系统按"睡眠电压点列表"从高到低逐点把目标通道压到该电压、经 MCU Status GPIO 让芯片进入/退出睡眠，同时用 UART 日志的"唤醒/入睡"心跳翻转判活；某电压点判死（崩溃/超时）即记录失败并触发恢复，最终给出可稳定工作的最低电压 Vmin。

布局：左侧 340px 配置列（Device Connection / Test Config，可滚动）+ 右侧监控区（Channel Config / 操作排 / Sweep Results 结果表）+ 底部 Execution Logs（UART 日志与判活过程）。

测试模式（Test Mode）

  • External Supply (N6705C)（默认，当前唯一已实现）— N6705C 直接作电压源供电，无需校准。
  • Internal Voltage (IIC) — 预留：N6705C 作电压表、经 IIC 控制字调节芯片内部电压，需电压校准。当前点击 Start Hunt 会提示 "Not Implemented"。

提示：Test Mode 下拉已禁用鼠标滚轮切换，防止页面滚动时误改（点击展开仍可选，程序导入配置不受影响）。

设备连接（Device Connection）

  • N6705C — 电源/电压源，搜索-选择 VISA 地址-连接。
  • UART (DUT Log) @ 921600 — 串口连接 DUT 日志，是判活与匹配规则的来源；右侧串口设置里有 Alive Rule 选项卡可自定义匹配正则（见下文"UART Log 匹配规则"）。
  • MCU PWR / RESET — MCU IO（PwrON/Reset/Status/Ctrl）。Status 行必须勾选并使能，用于拉睡眠/唤醒电平；Reset/PwrON 可选，用于死机恢复。
  • Chamber — 温箱，仅勾选 Temperature Control 时显示。

测试配置（Test Config）

  • Test CNT — 每个电压点的测试循环次数（正整数）。
  • Test Mode — 见上文，默认 External Supply。
  • Temperature Control — 勾选后展开 Temp Points (°C)（逗号分隔，如 -40, 25, 85）并显示 Chamber 连接卡。
  • Monitor Channels — VcoreM 必选（勾选框禁用）；VcoreL 可选，勾选后追加 VcoreL 的 N6705C 通道/限流、IIC 控制字与 VcoreL Sweep 选项卡。
  • Voltage Sweep Configuration — 选项卡式（VcoreM Sweep / VcoreL Sweep），每项四个参数：
    • Default (V) — 默认/唤醒电压，睡眠点之间的恢复电压。
    • Sweep Start (V) — 扫描起始电压（通常较高）。
    • Sweep End (V) — 扫描结束电压（通常较低）。
    • Step (V) — 步进（正值），方向由 Start→End 自动判定。
    系统按 Start/End/Step 自动生成电压点列表（≤10000 点），默认 0.80 → 0.60、步进 0.05。底部 hint 随当前选项卡提示对应通道。

通道配置（Channel Config）

  • N6705C 通道 — VcoreM Ch / VcoreL Ch（1-4）与各自 Current Limit (mA)（0.1-5000，默认 20.0），通道开启时施加该限流。
  • VcoreM IIC / VcoreL IIC — IIC 控制字：Device Addr、Bit Width（8/10/32）、Sleep Addr 与 Normal Addr 各带 MSB/LSB。仅 Internal 模式用；External 模式下用于开局的"配低"写读校验（可选）。

UART Log 匹配规则（Alive Rule）

判活完全靠 UART 日志逐行正则匹配。规则来源优先级：串口设置 Alive Rule 选项卡的自定义值 > 页面默认。三个正则均可留空（空串不参与判定）：

  • Alive pattern（判活成功标志） — 命中即认为芯片存活。默认：retention check success
  • Wake regex（唤醒） — 命中表示芯片被唤醒（sleep=0）。默认：sleep_pin_irqhandler:.*\bsleep=0\b
  • Sleep regex（进入休眠） — 命中表示芯片进入睡眠（sleep=1）。默认：sleep_pin_irqhandler:.*\bsleep=1\b

Alive Rule 选项卡底部有 Preview：粘贴 DUT 日志行可实时统计 alive/wake/sleep 命中数，正则非法时红字报错。

匹配样例

以下三行 DUT 日志分别命中 wake / sleep / alive：

sleep_pin_irqhandler: pin=12 val=1 sleep=0 cnt=2   → 命中 Wake regex
sleep_pin_irqhandler: pin=12 val=0 sleep=1 cnt=2   → 命中 Sleep regex
retention check success                            → 命中 Alive pattern

要点：\b 是词边界，确保 sleep=0/sleep=1 完整匹配（不会误命中 sleep=10）；.* 允许 IRQ 行中间夹任意字段（pin/val/cnt 等）。若你的固件日志格式不同（如 [SLEEP] enter/[SLEEP] exit），把 Wake/Sleep regex 改成对应文本即可，例如 Wake=\[SLEEP\] exit、Sleep=\[SLEEP\] enter。

操作与结果

  • Start Hunt — 校验参数后启动遍历；期间禁用，Stop 解锁。
  • Stop — 协作式停止，跑完当前步骤后收尾。
  • 睡眠电压探测（默认勾）/ 唤醒电压弹窗 — 测试项开关（导入导出配置会保留）。
  • Vmin 汇总 — 操作排右侧实时显示 Vmin: x.xxx V（hunting 中显示 hunting...）。
  • ⤓ Export Results — 把结果表导出为 CSV。

Sweep Results 表七列：Voltage (V) / Temp (°C) / Channel / Pass/CNT / Status / Flag Log / Note。Status 为 FAIL/CRASH/HANG 标红、PASS 标绿；Flag Log 列悬浮可看完整内容（多行 tooltip）。

执行流程（External Supply）

  1. 前置校验：N6705C 已连接、MCU IO 已连接、Status GPIO 已使能并配置合法；否则弹错不启动。
  2. 按相位执行：先 VcoreM 相位；若勾了 VcoreL 再追加 VcoreL 相位（另一通道固定为其 Default 电压）。
  3. 每个相位：N6705C 设限流并开输出 → 可选 IIC 配低校验 → 逐睡眠点压压 → Status GPIO 睡眠/唤醒 → UART 判活（唤醒/入睡翻转或 alive 命中）。
  4. 判死（崩溃关键字/超时）时经 Reset（若配置）恢复，记录该点失败。
  5. 收尾：PWR/RESET/Status 控制 IO 释放为高阻，避免一直驱动 DUT；刷新 Vmin 汇总。

配置导入 / 导出

  • Import Config / Export Config（页头右侧）— JSON 格式，字段覆盖 Test CNT / Test Mode / 温度 / 监测通道 / 电压扫描 / N6705C 通道限流 / IIC 控制字 / UART 端口波特率 / Alive Rule 正则。
  • 兼容旧版 voltage_points 列表（自动换算 Start/End/Step）。

注意：本页为 UI 与交互层；遍历引擎（SleepVminEngine）、电压校准、死机判定与恢复编排在 core 层经 QThread 异步执行，结果经 Signal/Slot 回填。
