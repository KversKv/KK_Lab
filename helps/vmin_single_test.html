Single Vmin Test（单次 Vmin 测试）

页面介绍

Single Vmin Test 是 VminHunter 的子页面，用于在 Vmin Hunt 探底找到最低稳定工作电压（Vmin）后，在指定电压点单次执行完整 Vmin 测试序列，确认测试流程与结果。

测试序列

  1. N6705C 输出唤醒电压（Default），可选 IIC 将芯片内部电源配到最低。
  2. STATUS IO 触发 DUT 进入睡眠，随后把 Vcore 降到指定 Vmin 电压并保持。
  3. Vcore 恢复到唤醒电压，STATUS IO 触发唤醒。
  4. 通过 UART 日志判活（sleep=0/1 翻转 + 崩溃关键字 + 超时），按 Test CNT 重复迭代。

配置说明

  • Test CNT — 在该 Vmin 电压点的迭代次数。
  • Test Mode — 当前仅支持 External Supply (N6705C)。
  • Monitor Channels — VcoreM 必选；VcoreL 可选（勾选后按 VcoreM → VcoreL 两阶段依次确认）。
  • Default (V) — 唤醒 / 恢复电压。
  • Vmin (V) — 需要确认的睡眠电压点（探底得到的 Vmin）。
  • Channel Config — N6705C 通道、限流与 IIC 控制字，与 Vmin Hunt 页一致。

使用方法

  1. 连接 N6705C、UART（DUT Log）与 MCU PWR / RESET。
  2. 填写 Default 与 Vmin 电压，确认 Channel Config。
  3. 点击 Start Test 执行单次序列；结果表给出该电压点 PASS/FAIL 与判活详情。

提示：可用 Import Config 导入 Vmin Hunt 页导出的配置，Vmin 电压会自动取电压点列表中的最小值，请按实际探底结果修正。
