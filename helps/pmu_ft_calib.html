PMU — FT Calibration Check（FT 校准检查）

页面介绍

FT Calibration Check 页面用于集中执行各模块的 FT（Final Test）校准数据检查。页面顶部子项 Tab 切换检查对象：

  • GPADC — 复用 GPADC Test 的两点 FT 校准检查流程（测试项已锁定为 FT Calibration Check，配置记忆与 GPADC Test 页相互独立）。
  • Output Voltage Check — 逐 rail 输出电压校准检查：读 EFUSE 校准码，按偏移/绝对模式写入 Vbit 位域调压，用 DMM 或 N6705C VMeter 实测 DUT 电压并按容差判定 PASS/FAIL。

GPADC — 两点 FT 校准检查

用户提供两个 FT 校准电压点及对应校准码（ADC raw code），系统按 Data Acquisition 选择分两种方式检查：

  1. IIC 方式（两步） — 第一步「校准点确认」：N6705C 依次施加两个校准电压，IIC 实时采样 GPADC raw，与用户校准码比对（容差 Raw Tol ±LSB）；第二步用用户两点解出 K/B（code = K·V + B），对 Start/End/Step 遍历范围逐点采样并换算校准电压，评估其与实际施加电压的误差。
  2. UART Log 方式 — DUT 内部已带校准计算，逐点从日志 raw/volt=<raw>/<volt> 同时提取 raw 与 volt（volt 单位 mV）：校验 volt 与施加电压的误差；同时用用户两点 K/B 反推电压 (raw − B)/K，校验其与 DUT volt 的一致性（K,B Consistency）。

判定与输出：Max/Avg/RMS 误差统计；任一项超出 Error Limit ±mV（IIC 含校准点确认）即判 FAIL。指标卡含 P1/P2 偏差（仅 IIC）、MAX/RMS ERR、CONS MAX（仅 UART）与 RESULT；曲线主图为理想曲线（y=x）+ 校准电压传输曲线，下方子图为误差 vs 施加电压（带 ±Limit 判定线，UART 叠加一致性曲线），X 轴联动；导出 Excel 含 Summary（K/B、校准点确认、误差统计、判定）+ Sweep Data 两个 sheet。

分压比（Divider Ratio，默认 1）：外部有分压电路时设置为 源设定电压 / DUT 引脚电压（如外部四分压填 4）。扫压 Start/End/Step 为源设定电压（按原值输出，不放大）；DUT 侧得出的校准电压按 × 比值 还原到源域后，与设定值比对评估误差。校准点电压填写 DUT 引脚电压（FT 标称值），IIC 确认时源输出自动按 点电压 × 比值 折算。

Calib Raw 1/2 输入：支持十进制 / 0x 十六进制及 base±offset 自动求值（如 0x13F+2000→2319），仅内部求值，输入框保留原始表达式文本。

注意：两种方式都需要连接 N6705C 扫压；本检查不应用 Algorithm 采样算法与 Outlier Filter 离群筛选（保持 raw 与 volt 配对一致），两区在本页自动隐藏。测试结束（含中止或异常）后，扫压通道的电压、模式及输出开关自动恢复为测试前状态。

测试方法

  1. 连接 N6705C 电源作为精确电压源
  2. 通过 I2C 连接到 DUT（或连接 DUT 串口选择 UART Log 采集）
  3. 填写两个 FT 校准点（电压 V + 校准码 LSB）与 Raw Tol / Error Limit 阈值，按需设置分压比
  4. 设置扫压 Start/End/Step，点击开始测试
  5. 查看指标卡与校准曲线 / 误差子图判定 PASS/FAIL，可导出 Excel 或在 Recent Tests 载入历史记录

Output Voltage Check — 输出电压校准检查

按「芯片 → 多个 DCDC/LDO rail」组织校准验证。核心流程：读取 EFUSE 校准 trim → 按模式计算校准码 → 写入指定 Vbit 寄存器位域调整输出电压 → 测量 DUT 实际电压 → 与目标电压按容差判定。

芯片管理（Manage Chips）

  • 芯片库保存在 user_data/ft_calib_ov_chips/chip_library.json，支持 Import/Export JSON 交换（重名芯片导入时确认覆盖）。
  • 芯片级配置：I2C 设备地址 / 位宽（8/10/32/8x8）/ 速度；EFUSE 链路二选一——script（厂商时序脚本，下拉选择脚本，含 EFUSE_SCRIPTS 旧芯片脚本与 best1811/best1860 等按芯片分目录的脚本）或 i2c（EFUSE 映射为普通寄存器直接读）。
  • 每个 rail 配置：Vbit 位域（寄存器地址 + MSB/LSB，位宽可继承芯片）、EFUSE 字段（地址/偏移 + MSB/LSB，支持 Signed 补码或 Sign Bit 独立符号位）、校准模式、目标与容差。
  • 已预置 BES1811 / BES1860 芯片库（各 11 个 rail：BUCK1-6 + VREG_L7-L11），基准 BT1811_BT1860_FT_Efuse_V01.xlsx：EFUSE 走各自 PMU 脚本（best18xx/efuse_scripts/efuse_18xx_pmu.py），trim 为「幅度位域 + 独立符号位」格式（Sign Bit，1=负），mode=offset（code = FT 基准码 + trim），目标为 FT 标称电压，容差默认 ±20mV 可按需调整。BUCK 默认用小 BG trim（EFUSE 0x2/0x3），大 BG 场景把 EFUSE 地址改为 0x4/0x5。

校准模式与判定

  • offset 模式：code = Base Code + EFUSE值 + Offset（EFUSE 为相对基准码的偏移量）。
  • absolute 模式：code = EFUSE值 + Offset（EFUSE 即绝对校准码）。
  • 目标电压二选一：config 直接填写目标 (mV)；derived 按 code × Step (mV/LSB) + Base Voltage (mV) 推算。
  • 判定：|实测 − 目标| ≤ Tolerance (mV) 判 PASS（边界含等号）；超出位域范围的码自动钳位并告警。

测量仪器

  • Keysight 34461A (DMM)：页内连接卡扫描/手填 VISA 地址后连接；Samples/NPLC/Range 可配，多次采样取平均（精密容差判定优先 DMM）。
  • N6705C VMeter：复用电源连接，选择 VMeter 通道；仅测压模式（VMETer），3 次读数取平均。

运行与恢复

  1. 选择芯片，在 DUT (Rail) 下拉中选择本次要校准的 1 路 rail（当前仅支持单路）；下方 EFUSE / Vbit 地址与配置区可直接查看并修改，校验通过即写回芯片库 JSON 并生效。
  2. 选择测量仪器并连接，按需勾选 Restore registers（默认开）与 Stop on first FAIL。
  3. 点击 Start Check 执行所选 rail；结果表给出 EFUSE/码/目标/实测/误差/判定，误差图带 ±容差参考。
  4. 结束（含停止/异常）后按勾选统一恢复所有写过的 Vbit 寄存器原值；Export CSV 导出到 Results/。

注意：EFUSE 脚本读取与 DMM 批量采样为不可中断的仪器操作，Stop 响应粒度为 rail 边界；EFUSE 读失败会中止整轮（避免错码调压）。写码后自动 readback 校验，不一致会告警并记录。
