N6705C Datalog 帮助手册

页面介绍

Datalog 页面用于通过 Keysight N6705C 直流电源分析仪进行长时间数据采集（Datalog），实时记录各通道电压、电流、功率随时间变化的波形，并提供 Marker 区间分析、测量统计、自定义标注、数据导入导出与一键截图等完整分析能力。支持双仪器（最多 8 通道）同步采集。

快速上手（基础流程）

  1. 连接仪器 — 点击左侧图标栏的 Instrument Connection 图标打开连接面板，点击搜索按钮扫描局域网内的 N6705C，在设备卡片上点击 Connect；已连接设备自动分配到插槽 A / B / C / D。也可以通过「⋯」菜单 → Add Instrument Manually 手动添加（TCP/IP 或 USB）。
  2. 配置采集参数 — 点击左侧 Settings 图标，在 DATALOG CONFIG 中设置 Sampling Period (μs) 采样周期与 Monitoring Time (s) 监控时长；勾选 Minimum 可自动使用最小采样周期。
  3. 选择测量项 — 在 Measurement Settings 中勾选需要统计的指标（Minimum / Average / Maximum / Peak to Peak / Charge / Energy）。
  4. 勾选采集通道 — 在下方 Channel Config 的 Active 页签中，为每个通道勾选 I（电流）/ V（电压）/ P（功率），必要时调整 Scale / Offset。
  5. 开始采集 — 点击底部 Start Recording，采集过程显示进度条，完成后波形自动绘制到图表中。
  6. 分析数据 — 使用图表工具栏的 Marker A / B 圈选区间，测量表自动统计区间内数据；悬停波形可查看各通道瞬时值。
  7. 导出数据 — 点击底部 Export Datalog 导出 CSV 或 DLOG 文件。

提示：点击右下角帮助按钮（问号图标）打开本手册，并使用「一键引导」跟随高亮提示逐步完成上述流程。

界面布局

  • 左侧图标栏 — Settings（采集/测量设置）与 Instrument Connection（仪器连接）两个面板互斥单开；未连接仪器时默认展开连接面板，已连接时全部收起。
  • Datalog Viewer — 中央波形区，多通道纵向分带（band）显示；左侧通道名标签可双击重命名。
  • MEASUREMENT — 波形下方的测量统计表，显示 Measurement Settings 中勾选的指标；放置 Marker 后统计范围限定在标记区间内。
  • Channel Config — 底部通道配置区，Active 页签管理已连接仪器的通道，导入的文件各有独立页签（可关闭）。
  • 底部控制栏 — Start Recording / Export / Import 靠左；设置齿轮（五标签设置对话框）与帮助按钮靠右。

图表工具栏

  • Box Zoom — 框选缩放模式（开启 4 秒后自动关闭）
  • Fit View — 自动适配视图，显示全部数据
  • Marker A / Marker B — 进入放置模式后在图表上点击放置标记线
  • Add Markers — 将当前 A/B 标记保存为一组命名标记
  • Clear Markers — 清除所有标记线
  • Time Offset — 仪器 B 波形时间偏移对齐（仅双仪器模式可见）

波形交互

  • 点击通道区域 — 选中该通道（高亮其 band 区域）
  • 上下拖拽 — 调整选中通道的纵向偏移
  • 鼠标滚轮 — 缩放选中通道的纵向比例
  • 悬停 — 显示十字线与各通道当前时间点的数值 Tooltip
  • 拖拽标记线 — 直接移动 Marker A / B
  • Reset View — 见 Fit View，一键恢复全览

Marker 区间分析

  1. 点击 Marker A 后在图表上点击放置标记线 A，同法放置 Marker B。
  2. A/B 之间区域高亮显示，测量表自动统计区间内的各项指标。
  3. 标记线可拖拽微调；右键 Marker 按钮可快捷操作。
  4. 双仪器模式下，可用 Marker 自动计算两台仪器之间的时间偏移量。

双仪器模式（8 通道）

  • 连接两台 N6705C（分别占用插槽 A 和 B）即可同步采集 8 个通道。
  • 通道名自动加 A- / B- 前缀区分来源。
  • 使用 Time Offset 对齐两台仪器的时间基准。

数据导入 / 导出

Import Datalog 支持以下格式，导入数据以 F1-、F2- 等前缀与实时数据区分：

  • .csv — 首列为时间，后续列为各通道数据；支持附带 [CUSTOM_LABELS] 与 [CH_NAME_RENAMES] 段
  • .dlog — Keysight 原始二进制 Datalog 格式
  • .edlg — Keysight 扩展 Datalog 格式

Export Datalog 支持导出：

  • .csv — 时间列 + 全部通道数据；双仪器分 Time_A(s) / Time_B(s) 两组时间列；同时导出自定义标注与通道重命名信息
  • .dlog — 原始二进制 Datalog 数据（需先有采集或导入的原始数据）

自动保存（DLog Save）

在设置对话框的 DLog Save 页签中可开启录制正常结束后的自动写盘（.dlog），支持命名模板占位符 {date} / {time} / {datetime} / {seq}（递增序号）。录制出错时自动跳过保存。

设置对话框（底部齿轮）

  • Instruments — 管理默认仪器（增/改/删）与每台/全局自动连接
  • Network Scan — 配置设备搜索的额外网段
  • DLog Save — 自动保存目录与命名模板
  • Waveform Summary — 波形摘要事件检测算法参数
  • About — 版本信息、配置目录、还原默认设置

一键截图与波形摘要

  • 一键截图 — 标题栏截图按钮将 Datalog 波形 + MEASUREMENT + Channel Config 区域截取为图片并复制到剪贴板。
  • 波形摘要 — 标题栏摘要按钮将波形压缩为平直线段示意图（标注 S1..Sn）+ 阶段汇总表，复制到剪贴板，便于粘贴给 AI 分析。

自定义标注（Custom Labels）

通过标题栏的标签按钮展开 CUSTOM LABELS 面板：选择通道、输入时间点与文字，点击「+」在波形上添加文字标注；标注随 CSV 一同导出。

常见问题

  • 搜索不到设备？ — 确认仪器与电脑在同一局域网；在设置对话框 Network Scan 页签中添加仪器所在网段后重新搜索；或改用「⋯」→ Add Instrument Manually 手动添加。
  • Start Recording 不可点？ — 需至少连接一台仪器且在 Channel Config 中勾选了至少一个通道的测量类型（I / V / P）。
  • 波形超出显示范围？ — 在 Channel Config 中调整对应通道的 Scale / Offset，或点击 Fit View 自动适配。
  • 没有仪器也想体验？ — 调试模式（DEBUG_MOCK）下自动生成模拟设备与随机数据，可无仪器体验完整流程。

快捷操作一览

  • 点击波形区域 — 选中通道
  • 拖拽（选中通道）— 纵向偏移波形
  • 滚轮（选中通道）— 缩放纵向比例
  • 双击通道名 — 重命名通道
  • 右键插槽 — 断开连接菜单
  • Esc — 退出一键引导
