Power Control

页面介绍

Power Control 页面用于通过 Keysight N6705C 或 ITECH IT2705 直流电源对 DUT（被测设备）进行实时电压/电流监测、输出控制与功耗分析。手动或自动连接后，页面通过 *IDN? 返回值识别并显示真实仪器型号。

测试项

  • 实时电压/电流监测 — 实时读取各通道的输出电压和电流值
  • 多通道管理 — N6705C 支持 4 通道，IT2705 支持 8 通道；双仪器按各自实际通道数独立配置与监测；启动、切回本页及切换通道时自动回读当前通道的模式、输出状态与设定参数
  • 输出控制 — 开启/关闭各通道输出，设置电压和电流限值
  • 批量与功耗测试 — 按仪器实际通道执行批量设置和 Current Consumption Test
  • Arb Set（任意波形） — 在 Current Consumption Test 下方折叠区内为任一通道配置 Arb：先选 Arb Type（Voltage / Current），再选波形（No Arb Configured / Sine / Step / Ramp / Staircase / Pulse / Trapezoid / Exponential / Constant Dwell / User Defined，各带波形图示；Constant Dwell 与 User Defined 用逗号分隔列表输入电平点），以及 Continuous 连续重复（未勾选时可在 Repeat Count 设置执行次数）与结束方式（Return to DC Value 结束后回 DC 设定 / Last Arb Value 保持最后 Arb 值）；左栏下方单按钮 RUN / STOP 按当前通道运行态自动切换，中栏参数区、右栏按当前参数实时绘制的波形示意图；通道标签与上方电压区相互独立，各通道参数自动记忆；IT2705 通道不支持 Constant Dwell / User Defined / Sequence（选项禁用），Sequence 编辑将在后续版本提供；右侧 Quick Presets 可将当前配置命名保存（持久化到 user_data/n6705c/arb_presets.json），点击预设仅回填编辑区，Delete 删除选中预设
  • 通道同步 — 在 Quick Setup 通道按钮上右键 → Sync 勾选要同步的通道（可多选/分多组）；同步组内仅序号最小的主通道可编辑电压/限流，其余成员输入框禁用并实时镜像主通道值，同组通道按钮与从通道输入框以同色边框区分；执行 Set 时任一成员被勾选即整组按主通道的电压和限流统一下发

测试方法

  1. 在左侧连接区域搜索或手动输入 VISA 地址，连接 N6705C / IT2705 设备
  2. 确认连接状态中的真实型号，选择需要使用的通道
  3. 设置目标电压和电流限值，开启通道输出并观察实时读数
  4. 根据需要执行批量设置或功耗测试并记录数据
