PMU — PSRR Test（电源抑制比测试）

页面介绍

PSRR Test 页面支持 MSO64B + J2120A 和 Audio Precision 两种测量方式。MSO64B + J2120A 方式使用 N6705C 提供直流偏置、MSO64B 内置 AFG 经 J2120A 注入正弦纹波，并由示波器两个通道测量输入与输出纹波 RMS，按 PSRR = 20 × log10(Vin / Vout) 计算各频点的电源抑制比。

测试参数

  • Measurement Method — 选择 MSO64B + J2120A 或 Audio Precision，左侧配置区随测量方式切换
  • Excitation — 设置 N6705C 源通道、直流偏置、AFG 幅度（mVpp）、Start Frequency、End Frequency 和 Points；系统按对数等间隔生成频点并包含起止点
  • Acquisition & Limit — 设置输入/输出示波器通道、捕获周期数、输出通道量程和最小 PSRR 判定限值
  • Audio Precision — 设置连接方式、Project Path（可选）、Signal Path、Signal Analyzer、输出通道、Output Amplitude、DC Offset、Start Frequency、End Frequency、Points 和判定限值；输入带宽自动覆盖最高测试频率
  • AP Connection — Local AP Direct 在主机运行 APx500；Virtual Machine SSH 在 Guest 运行 APx500。虚拟机默认使用已验证的 SSH Profile testvm，Guest IP 192.168.208.128 作为无 Profile 时的回退，SSH 用户为 administrator、端口 22、Python 命令为 py -3.12
  • Turn off source channel after test — 勾选后在测试结束、停止或异常时关闭源通道；未勾选且通道测试前已开启时保持开启

MSO64B + J2120A 测试方法

  1. 连接 N6705C 与 MSO64B，将 AFG 输出接入 J2120A，并将输入纹波和 DUT 输出分别接入两个不同的示波器通道
  2. 确认探头、接地和通道量程适合被测信号；两个测量通道均使用 AC coupling
  3. 配置直流偏置、AFG 幅度、起止频率、点数、捕获周期和判定限值；End Frequency 必须大于 Start Frequency，并确保正弦峰值不会使电源输出过零
  4. 点击 START TEST，系统逐频点输出 AFG 正弦激励，经预览与正式两阶段时基采集后记录输入/输出 RMS 原始数据并计算 PSRR
  5. 查看最小/平均 PSRR、最差频点、限值判定和对数频率曲线；点击 STOP 可软停止当前测试

Audio Precision 测试方法

  1. 选择 Local AP Direct 时，在主机安装 APx500 与 pythonnet 并连接 Audio Precision 仪器；选择 Virtual Machine SSH 时，在 Guest 安装 APx500 5.0 与 Python 3.12/pythonnet，并完成 APx525 USB 直通。将指定模拟输出通道接入 DUT VIN，AP INPUT 1、INPUT 2 分别接 DUT VIN、VOUT
  2. 虚拟机模式通过 SSH stdin 发送当前驱动与测试脚本，不依赖共享目录中的旧副本；Project Path 按实际运行 APx500 的主机或 Guest 文件系统解释，留空则使用当前 APx 项目
  3. 输出固定为 Analog Unbalanced Sine，默认 100 mVrms、3.8 VDC Offset；输入 High-pass=DC、Low-pass=ADC passband、Weighting=None、EQ=None
  4. 系统按最高扫频频率自动选择 20k/40k/80k/250k/500k/1M Hz 输入带宽，最高测试频率不能超过 1 MHz
  5. 每个频点只执行一次 Signal Analyzer FFT 采集，再从同一帧 FFT Spectrum 分别读取 CH1、CH2 的最近频点 dBV 电平，按 PSRR=CH1(dBV)-CH2(dBV) 计算
  6. 测试结束、停止或异常时关闭 AP 发生器；关键仪器设置或 FFT 读取失败会中止测试并报告错误

注意事项

  • 低频点的正式采集需要等待 16 倍时基，单个频点可能耗时较长
  • 测试结束后框架会关闭 MSO64B AFG，并恢复 N6705C 测试前电压和通道状态；仍建议在真机测试前确认 DUT 供电与 J2120A 接线
  • SSH 连通不代表 APx525 USB 已直通；若 APx500 处于 Demo Mode，测试会在开启发生器前明确失败
  • Mock 模式只生成确定性演示数据，用于验证界面与扫频流程，不代表真实硬件测量结果
